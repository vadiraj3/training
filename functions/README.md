# JavaScript Functions Training Module

Welcome to the Functions training module! This project is designed to help you master the core of JavaScript: Functions.

## Getting Started

1.  Navigate to this directory in your terminal.
2.  Install dependencies: `npm install`
3.  Start the training dashboard: `npm run dev`
4.  Open the provided URL (usually `http://localhost:5173`) in your browser.

## How to Train

1.  **Read the Lesson**: Open the training dashboard in your browser. Start with Lesson 1.
2.  **Understand the Concepts**: Read the "Teacher's Explanation" and look at the "Code Examples".
3.  **Complete the Task**: 
    -   Find the task description in the "Trainee Task" section.
    -   Open the corresponding exercise file in `src/exercises/` (e.g., `Lesson1.js`).
    -   Write your code as per the requirements.
4.  **Verify**: You can use the browser console to see the output of your functions if you call them in your exercise files.

## Curriculum

- **Lesson 1**: Defining Functions (Normal vs Arrow)
- **Lesson 2**: Function Parameters
- **Lesson 3**: Using Functions (Direct calls & Events)
- **Lesson 4**: Multiple Parameters & Default Values
- **Lesson 5**: Return Statements & Storing Results
- **Lesson 6**: Inline & Anonymous Functions

Happy Coding!
